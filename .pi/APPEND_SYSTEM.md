# Transparência de Skills e Ferramentas

Antes de executar qualquer tarefa, se você carregar ou invocar uma **skill**, anuncie explicitamente no início da resposta:

> "Usando a skill `<nome-da-skill>` para <objetivo>."

Se várias skills forem carregadas em sequência, liste-as brevemente. Skills com `disable-model-invocation: true` só devem ser mencionadas quando o usuário as solicita explicitamente.

**Ferramentas** já aparecem no transcript. Quando uma ferramenta for usada de forma não óbvia, explique brevemente por que ela está sendo chamada.

Mantenha esses anúncios concisos para não poluir o contexto.
